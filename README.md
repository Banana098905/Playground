# PLAYGROUND ZERO

> 作る。壊す。発見する。また作る。

ブラウザだけで創作と実験を楽しめる、近未来的なデジタル創作基地。
既存のポートフォリオとは**完全に独立した静的Webサイト**です。公開後はURLをポートフォリオに貼るだけで紹介できます。

- 依存ライブラリ **なし**（HTML / CSS / JavaScript のみ、ビルド工程不要）
- ユーザー登録・サーバー **不要**（作品はブラウザの IndexedDB に保存）
- GitHub Pages のサブパス（`https://user.github.io/playground-zero/`）でも独自ドメインでも動作

## 機能

### Phase 1（すべて維持）

| ページ | できること |
|---|---|
| **Home** | 世界観ヒーロー、今日の実験テーマ、新しい実験、最近の作品、各ページへの導線 |
| **Studio** | 図形とテキストの追加／移動・拡大縮小・回転／色・線・不透明度・角丸／前面・背面／複製・削除／元に戻す・やり直す／自動保存／PNG書き出し |
| **Lab › Particle Lab** | 粒子の数・速度・大きさ・色／マウス（タッチ）反応／残像／一時停止・リセット |
| **Lab › Shape Machine** | 図形の自動生成／シード固定で再現／ランダム設定／Studioへ引き継ぎ |
| **My Space** | 作品一覧・プレビュー・編集・複製・削除（直後なら元に戻せる）・バックアップ |

### Phase 2（新機能）

| ページ | できること |
|---|---|
| **Lab（実験ライブラリ）** | 実装済みの6実験を一覧。キーワード検索・ジャンル／タグ絞り込み・お気に入り・最近使った実験・**ランダムで開く**・各実験の使い方 |
| **Lab › Flow Field** | 風向き・強さ・乱れ・粒子数・速度・線の太さ・色／背景・3つの流れ（なめらか／渦／階段）・一時停止／再開・ランダム・初期状態へ・画像保存 |
| **Lab › Color Lab** | メインカラーから7種の配色（類似・補色・トライアド・テトラード・スプリット・モノクロ・明度違い）を生成・HSL調整・色の固定／個別編集・ランダム・HEX表示とコピー・お気に入りパレットの保存と再編集・他の実験へ配色を引き継ぎ |
| **Lab › Pattern Generator** | 8種の模様・対称（左右／上下／4方向）・密度・サイズ・色／背景・ランダム・**シードで同じ模様を再現**・PNG書き出し |
| **Lab › Motion Playground** | マウス／タッチに反応する5つの動き（追従・周回・反発・バネ・重力）・速度／強さ・形（5種）・色・自動で動かす・一時停止／再開・リセット |
| **Daily（今日の実験）** | 30種のお題が**その日の日付（端末の現地時間）**で切り替わる。同じ日は誰でも同じお題。説明・ヒント・関連ツールへのリンク・完了記録（メモ付き）・過去のお題一覧／さかのぼり。ログイン不要、毎日来なくても問題なし |
| **Discover（ランダム発見）** | ランダムな実験／配色／模様／流れ／お題を引く。シード表示・シード指定で再現・履歴・お気に入りとして保存・そのツールで開く（Spaceキーで引き直し） |
| **My Space（強化）** | 検索・7種の並び替え（名前／作成／更新ほか）・お気に入り・タグ・コレクション・複製・最近開いた作品・更新日時・種類での絞り込み・**JSONの書き出し／読み込み**（検証→確認画面→取り込み、既存の作品は上書きしない） |
| **作品から再開** | 実験の設定（params）を作品として保存 → 開き直すと同じ設定で再生成／そのまま調整／**派生保存**で元を残したまま v2 を作成。保存時に「画像で保存（見た目だけ）」と「作品として保存（再編集できる）」は別操作 |

> **実装していないもの**: 仕様書の例にあった「Sound Visuals」は未実装です（Web Audio 周りは端末差が大きく、未完成のまま出さない方針のため）。ライブラリには実装済みの実験だけが並びます。

## 起動

どれでも動きます。

```bash
# 1) Node.js がある場合（推奨）
npm start                 # → http://localhost:8080/

# 2) Python がある場合
python3 -m http.server 8080

# 3) とにかく開く
index.html をブラウザで開く（file:// でも動作。ただし一部ブラウザでは保存が制限されます）
```

> 保存機能（IndexedDB）を確実に使うには、1) か 2) のようにローカルサーバー経由で開くことをおすすめします。

## 公開（GitHub Pages）

手順は [`docs/DEPLOY.md`](docs/DEPLOY.md) にまとめています。要点:

1. GitHubに新しいリポジトリ（例: `playground-zero`）を作り、このフォルダを push
2. Settings → Pages → Source を **GitHub Actions** にする
3. `main` に push すると `.github/workflows/pages.yml` が自動で公開
4. 公開URLをポートフォリオにリンクとして貼る

サブパス対応はルーティングを `#/...`（ハッシュ方式）、アセットを相対パスにしているため、**設定変更なし**で動きます。独自ドメインは `docs/DEPLOY.md` を参照。

## データ保存とバックアップ（重要）

- 作品・お気に入り・コレクション・Dailyの完了記録は、すべて **このブラウザの IndexedDB** に保存されます。サーバーには送信されません。
- ブラウザのデータ削除・シークレットモード・端末変更で **消えることがあります**。
- **バックアップ方法**: My Space →「バックアップ」で、作品・コレクション・Daily完了記録・お気に入り実験をまとめた JSON を書き出します。別のブラウザや端末では「読み込み」で復元できます。7日以上バックアップがないと My Space で通知します。
- **取り込みの安全性**: ファイルを選ぶと、まず中身を検証して**確認画面**（新規／別作品として追加／スキップの件数、警告）を表示します。「取り込む」を押すまで何も変わりません。既存の作品を上書きすることはなく、同じIDで内容が違う場合は「（取り込み）」を付けた別作品として追加します。壊れたファイル・別アプリのファイル・不正な構造は拒否します。
- **画像保存とデータ保存は別物**です。PNG は見た目だけで再編集できません。再編集したいときは「作品として保存」またはJSONを使います。
- Phase 1 のバックアップ（形式1）も、そのまま読み込めます。Phase 1 で保存した作品は、更新後もそのまま My Space に表示され、Studio で開けます（データ移行・初期化は不要）。
- IndexedDB が使えない環境では localStorage、それも不可ならメモリに自動で切り替え、画面上で警告します。

保存形式の詳細は [`docs/DATA-FORMAT.md`](docs/DATA-FORMAT.md) を参照。

## ディレクトリ構成

```
playground-zero/
├─ index.html            エントリ（スクリプトの読み込み順に意味あり）
├─ 404.html / robots.txt / manifest.webmanifest / .nojekyll
├─ assets/               ロゴ・favicon・OG画像
├─ css/style.css         デザインシステム（トークン→基本→部品→各ページ→レスポンシブ）
├─ js/
│  ├─ config.js          設定（名前・DB名・ポートフォリオURLなど）
│  ├─ util.js / ui.js    共通ユーティリティ・UI部品（モーダル、トースト等）
│  ├─ model.js           作品/オブジェクトのモデルと検証（sanitize）
│  ├─ render.js          Canvas描画・当たり判定・選択ハンドル
│  ├─ storage/           保存層（idb.js / fallback.js / index.js）
│  ├─ projects.js        作品サービス層（UIが呼ぶのはここだけ）
│  ├─ router.js          ハッシュルーター
│  ├─ userdata.js        お気に入り・最近使った実験・コレクション・Daily記録（IndexedDB meta）
│  ├─ registry.js        実験の一覧データ（名前・ジャンル・タグ・使い方）
│  ├─ labs-core.js       DOM非依存の生成ロジック（flow / color / pattern / motion）
│  ├─ daily.js           30種のお題と日付からの決定ロジック
│  ├─ pages/             home / studio / library / lab-* / daily / discover / myspace / workkit
│  └─ main.js            起動
├─ scripts/              serve / build / test-logic / check-links
├─ docs/                 DEPLOY.md / ARCHITECTURE.md / ROADMAP.md
└─ .github/workflows/    GitHub Pages 自動公開
```

## ポートフォリオとの連携

連携は **URLのリンクのみ** です。コードの共有・埋め込みはありません。
逆向きのリンク（PLAYGROUND ZERO → ポートフォリオ）が欲しい場合は `js/config.js` の `portfolioUrl` にURLを入れると、ヘッダーに戻りリンクが表示されます（空なら非表示）。
