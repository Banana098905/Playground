# 今後の拡張方針

## Phase 2 で実装したもの
実験ライブラリ／Flow Field・Color Lab・Pattern Generator・Motion Playground／Daily Experiment／Random Discovery／My Space 強化（検索・並び替え・タグ・コレクション・JSON書き出し／読み込み）／作品からの再開と派生保存。

未実装: **Sound Visuals**（仕様書の例にあったが、端末差の大きい音声入力まわりのため見送り）。

## Phase 3 の改善案（サーバー不要で続けられるもの）
- **Sound Visuals**: 音ファイルの読み込み／マイク入力（許可制）に反応するビジュアル。まず音ファイル再生のみから
- **Studio との相互運用**: Pattern / Flow の出力を Studio のレイヤー画像として取り込む、Color Lab のパレットを Studio の色プリセットにする
- **My Space**: 複数選択での一括タグ付け・一括削除、コレクションのドラッグ整理、作品の並べ替え（手動）、派生の系統図（parentId を使ったツリー表示）
- **Daily**: 連続達成の表示、お題の自作（ローカル）、週間ふりかえり
- **Discover**: 発見の「ピン留め」、シード付き共有リンク（URLのみ。サーバー不要）
- **書き出し**: SVG / 高解像度PNG / アニメーションGIF（短いループ）
- **PWA化**: Service Worker でオフライン起動、ホーム画面に追加
- **自動バックアップ**: File System Access API による「フォルダへ自動保存」
- **アクセシビリティ**: 動きを減らす設定の全実験への反映強化、キーボードだけで操作できるスライダー群の整理
- **E2E テスト**: Playwright のシナリオ（保存→再開→派生→バックアップ復元）を CI に追加

## Phase 4 以降（サーバーが必要）
- アカウント・クラウド同期（`storage/` に `CloudRepo` を追加。`docs/ARCHITECTURE.md` 参照）
- 公開リンク／ギャラリー／コメント／ランキング
- AI による配色・構図提案、課金

## 技術的な見直しポイント
- コード量が増えたら TypeScript + Vite へ移行（`PZ.*` のモジュール境界がそのままESMの境界になる）
- 作品が数千件規模になったら一覧のページング／仮想スクロールを IndexedDB のインデックス検索へ
- 履歴スナップショットを差分方式へ
